## 🛠️ Repository & Architecture Overview

All core planning, specs, and architecture guidelines are maintained in this primary repository:
* **Planning Repo:** `NatalieYocom/Aetheria`

The broader ecosystem consists of these target repositories:
* **`Aetheria-Social-Backend`:** C# .NET Web API (forked/built on `basisvr-social-service`).
* **`Aetheria-Unity`:** Unity 6 client ecosystem (built on `BasisVR/Basis`).
* **`Aetheria-Website`:** Web portal, user dashboard, and moderation panel.
