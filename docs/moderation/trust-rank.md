# Trust Ranks
The Trust Rank System calculates a dynamic, hidden Trust Score for every account based on positive engagement, account age, verified credentials, and moderation history. Players advance through five primary public tiers, which determine default avatar display permissions, lobby privileges, and creation limits.

## Visitor
New accounts are given this rank. They are restricted to pre-approved fallback avatars, cannot upload ay form of custom content, and cannot create any type of instance.

## New User
A visitor becomes a new user after **their email is verified and they have played the game for at least two weeks.** New users gain the ability to publish private worlds for personal use, create Friends+ and Invite+ instances, Use custom avatars and upload private avatars.

## User
After playing the game for **4 or more** weeks (or being promoted by an admin) A user gains all permissions including hosting public lobbies, using avatars, etc.

## Trusted User
After visiting 10 unique rooms, playing for atleast two months, and have not recieved more than 2 rule violations, a user becomes a Trusted User. If you recieve a rule violation, unless appealed, you will be demoted to User.

## Verified User
Gaining the Verified User trust rank can only be achieved if you **apply for it and get accepted.** Guidelines are listed in a different file.

## Platform Moderator
Handpicked by staff. Can kick people and can flag users for suspension, but not ban directly. Can approve and deny avatar upload requests.

## Staff Member
Can perform all moderation related actions, including suspensions, kicks, etc. Can join any room/instance, other than private instances. Can put rooms and avatars under review. Can review moderation logs and settings.
