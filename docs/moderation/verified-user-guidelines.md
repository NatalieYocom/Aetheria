# Requirements
You must fit one of these categories in order to be approved as a Verified User.

### Content Creator/Public Figure
Hold an active presence on social platforms (Youtube, Twitch, TikTok, etc) and hold numbers of atleast 1000 or more (subscribers, followers, etc)

### Featured Asset/World Creator
Has created at least 1 public world or custom avatar set that meets performance optimization standards and has reached community popularity thresholds (e.g., 500+ unique visits, 500+ unique avatar favorites)

### Group Owner/Community Organizer
Run a group or community that hosts public events, performance troupes, or educational meetups.
