## Avatar Moderation
Avatars will have 3 visibility types: Public, Private, and Unlisted

When public, all players will be able to equip the avatar from the public collection.
Although, after publishing a public avatar, it will only be visible to your friends until a moderator approves it.

When private, the avatar will stay private to the user who uploaded it, allowing the user to give people access to the avatar.

When unlisted, anybody with the avatar’s share link will be able to access the avatar. This is useful for YouTube/Discord avatars.

When using an Avatar, players are responsible for the actions they take in them.
An NSFW avatar will not be banned if used in a public lobby, rather the User will receive punishment instead.

This ensures that NSFW avatars can be shared without the risk of players using them to false ban the person who made the avatar.
