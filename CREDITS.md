# 📜 Credits & Acknowledgments

**Aetheria** is an open, public VR social platform built on open-source foundations and modular cloud infrastructure. This project stands on the shoulders of the open-source community, core upstream frameworks, and open specifications.

---

## 🏗️ Upstream Architecture & Frameworks

### **BasisVR & BasisVR Creator Group**
The core foundation of Aetheria's social backend and client ecosystem is powered by the open-source work of Luke (*dooly123*) and the **BasisVR Creator Group**.

* **BasisVR Client Framework (`Aetheria-Unity`):**
  * **Upstream Repository:** [`BasisVR/Basis`](https://github.com/BasisVR/Basis)
  * **Original Creator & Lead Maintainer:** Luke (*dooly123*)
  * **Role:** Native Unity 6 VR/Desktop social framework, client network pipeline, and `.bee` asset bundle system.

* **BasisVR Social Service (`Aetheria-Social-Backend`):**
  * **Upstream Repository:** [`basisvr-creator-group/basisvr-social-service`](https://github.com/basisvr-creator-group/basisvr-social-service)
  * **Role:** Core C# .NET Web API providing user identity, authentication, real-time presence, matchmaking, and asset indexing interfaces.

---

## 🐝 Asset & Catalog Standards

* **BeeBa Asset Standard:**
  * Created as the native asset bundle catalog and indexing specification for BasisVR.
  * Facilitates the packaging, distribution, and local/remote discovery of `.bee` avatars, worlds, and interactive prefabs across public networks.

## 🛠️ Infrastructure & Open-Source Libraries

Aetheria relies on the following open-source software, cloud frameworks, and infrastructure tools:

| Component | License / Project | Role |
| :--- | :--- | :--- |
| **Unity Engine** | Unity Technologies | 3D Client runtime & WebGL preview target |
| **MinIO** | AGPLv3 / Apache 2.0 | S3-compatible public asset & `.bee` storage host |
| **PostgreSQL** | PostgreSQL License | Relational database for accounts, roles, & asset records |
| **Redis** | BSD-3-Clause | High-performance pub/sub, caching, & live room state tracking |
